# Bank Marketing Campaign Analysis using SQL

Analyzed a bank marketing dataset using SQL to evaluate customer behavior and campaign performance. The project focuses on identifying key factors influencing term deposit subscriptions by applying data aggregation, segmentation, and advanced SQL techniques such as CASE statements and window functions.

## Objective

To uncover actionable insights that help improve marketing campaign effectiveness and customer targeting strategies.

## Dataset Used

https://github.com/NamrataVerma1998/Business-Analyst-Projects/blob/main/Banking%20Marketing%20Campaign/Banking_data.csv

## Key Insights

-Customers with longer call durations showed significantly higher conversion rates
-Certain job categories contributed more to successful subscriptions
-Age segmentation revealed which demographic groups are more likely to subscribe
-Customers with housing loans showed different subscription behavior compared to others
-Campaign performance varied across months, highlighting timing impact

## SQL Concepts Used

-Aggregate Functions (COUNT, SUM, AVG)
-Conditional Logic (CASE WHEN)
-Grouping & Filtering (GROUP BY, ORDER BY)
-Window Functions (RANK)
-Data Segmentation & Bucketing
